# slides

Öğrenciye açık sunum sürümleri için ayrılmış klasör. Henüz boştur.

Sınıfta kullanılan sunumlar bu depoda değil, özel `bit-ins/sunumlar/` klasöründedir; çünkü yalnızca sınıfta gösterilebilecek lisanssız görseller içerebilirler. Bir sunumun öğrenciye açık sürümü hazırlanırsa, yalnızca kendi üretilen, kamu malı ya da açık lisanslı görsellerle buraya konur ve her görselin lisansı yanına yazılır.
